state machine

A control surface for unfinished work. Not a pile of checkboxes. Not a status you perform on Friday.

A saved article, a naked URL, a half-made device — these are not always tasks. They are loops. Until the loop says what kind of unfinished it is, you keep re-deciding. The keyword is the next state, not a moral.

Device
System 96 (epistemic continuity): LOAD → SCAN → MARK → CARD → PLAY → ANKI → SIDE → CULL → NOTE → BLOG → LINK then DONE or DROP.
First state
LOAD, not READ. A bare URL has not earned attention. Materialize the source into the body of the system first.
Discard
SCAN may DROP. A system that cannot discard is a landfill with search.
Not this page
Working notes, Lightship of Theseus, the garden. Those live under /roam.

Dancing Machines uses [[state machine]] to mean this device, not a metaphor.
